## About Me

I work on Linux infrastructure, server automation, monitoring, and system hardening.
My focus is on creating practical tools and repeatable workflows that help manage production Linux environments with better reliability, visibility, and security.

I mainly work across:

* RHEL, Rocky Linux, CentOS, Ubuntu, and Debian-based systems
* Bash scripting and Linux automation
* Ansible-based provisioning and configuration management
* Monitoring with Nagios, NRPE, Grafana, Rsyslog, and related tools
* Server hardening, permissions, backups, log rotation, and operational security
* DNS, SMTP, SSH, NFS, Samba, FTP, firewalls, cron, and systemd services
