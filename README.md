## About Me

I am a Linux Administrator and DevOps automation enthusiast with hands-on experience in managing, troubleshooting, securing, and automating Linux infrastructure.

My work mainly focuses on building practical solutions for server operations, monitoring, automation, hardening, backup workflows, and production support. I enjoy creating clean Bash scripts, reusable Ansible playbooks, monitoring checks, and operational tools that make Linux infrastructure easier to manage at scale.

I work across environments based on **RHEL**, **Rocky Linux**, **CentOS**, **Ubuntu**, and other Linux distributions.
